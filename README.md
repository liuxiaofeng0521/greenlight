# 绿灯笔记

小红书文案违禁词检测工具。粘贴文案，一键检测，秒出结果。

## 特点

- 零注册、零下载，浏览器打开即用
- 纯前端检测，数据不上传服务器
- Aho-Corasick 多模式匹配，千字文案毫秒级出结果
- 102 个违禁词，覆盖广告法、化妆品法规、平台规则
- 高危/中危/低危 三级风险标注 + 替换建议

## 技术栈

纯 HTML + CSS + JS，零框架，零构建，零依赖。

## 部署

Vercel 免费部署，关联 GitHub 仓库即可自动上线。

## 词库更新

编辑 `data/banned-words.json`，提交到 GitHub，Vercel 自动重新部署。
