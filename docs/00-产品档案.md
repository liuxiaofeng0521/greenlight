## 技术栈

- 纯 HTML + CSS + JS，零框架，零后端
- 检测引擎: Aho-Corasick 多模式匹配 (detector.js)
- 词库: JSON 文件，102 个词，6 大类别
- 部署: Vercel (关联 GitHub，推送即自动上线)

## 竞品

- 零克查词: 需注册、词库更新慢、功能臃肿
- 句易网: 界面老旧、广告法为主、平台词不全

## 差异化

1. 零摩擦 — 不用注册、不用下载，打开即用
2. 词库更新快 — 社区共建，每周更新
3. 分级标注 — 高危/中危/低危，不贩卖焦虑
4. 替换建议闭环 — 不只告诉你问题，还告诉你解决方案
5. 规则教育 — 每次检测都在学规则

## 目标用户

小红书博主、品牌方运营、内容创作者、直播团队
