# 绿灯笔记 — 品牌手册

## 品牌名

**绿灯笔记**

零理解成本。小红书创作者都懂「绿灯 = 过审」。视觉联想统一（绿色 + 灯光）。

## 品牌主张

> **发之前，先过一遍。**

六个字。像出门前照镜子一样自然。不恐吓、不说教、不贩卖焦虑。

## 品牌人格

一个坐在你旁边的编辑朋友。

- 不居高临下说「你这样写不行」
- 轻声提醒「这个词可能有问题，要不要换一个」
- 靠谱、不装、温柔但有原则、快节奏不啰嗦

## 核心态度

规则是存在的，但我不贩卖恐惧。我把规则翻译给你，选择权在你手上。

不做「权威专家」，不做「平台代言人」。做「站在创作者这边的翻译官」。

## 三个「不说」

- 不说「警告」→ 说「这 3 个词建议换一下」
- 不说「违规」→ 说「这个词容易被限流」
- 不说「必须」→ 说「换成这些词可能更安全」

## 字体

系统字体栈: PingFang SC / Microsoft YaHei / sans-serif

## Icon

绿色圆形对勾 — 最直接的「安全通过」信号

## 文案风格

- 像朋友在群里打字聊天
- 带语气词但不泛滥
- 短句、人话、零爹味、零恐吓
- 不用「亲」「感谢您的反馈」等 AI 味/客服味表达

## 禁忌

- 不能说「官方认证」「100% 过审」「保证不违规」（违反广告法）
- 不能暗示「帮用户绕过审核」
- 不能攻击任何竞品公司或创始人
