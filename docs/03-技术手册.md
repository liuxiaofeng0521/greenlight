## 双远程 Git 工作流

```
origin  → GitHub (https://github.com/liuxiaofeng0521/greenlight)
gitee   → Gitee   (https://gitee.com/liuxiaofeng0521/greenlight)
```

### 日常修改流程（免梯子）

```bash
# 1. 本地修改代码
# 2. 推到 Gitee
git add -A && git commit -m "描述修改内容"
git push gitee master

# 3. 需要部署时，同步到 GitHub
git push origin master   # Vercel 自动检测并部署
```

### 查看远程

```bash
git remote -v
```

## Vercel 部署

- 关联 GitHub 仓库 liuxiaofeng0521/greenlight
- 框架预设: Other（纯静态）
- 每次 push 到 GitHub 自动部署

## 词库更新

编辑 `data/banned-words.json`，按现有格式添加/修改词条：

```json
{
  "id": "bw_NNN",
  "word": "违禁词",
  "level": "high|medium|low",
  "category": "分类key",
  "categoryLabel": "分类中文名",
  "suggestion": "替换建议 或 null",
  "description": "为什么违规",
  "reference": "法规依据"
}
```

更新 `meta.version` 和 `meta.totalWords`，然后推送。
